# Tangram 本地后端可选依赖（标准库即可运行主链路）
# ---------------------------------------------------------------------------
# 主链路（--chat / --bridge tcp / 记忆 / 工具 / 模型商店）只用 Python 标准库。
# 以下为「真实本地模型推理」的可选后端，按优先级惰性探测，缺失不影响启动：
#   llama_cpp      -> llama-cpp-python（GGUF 原生推理，推荐）
#   ctransformers  -> ctransformers（GGUF 原生推理）
#   transformers   -> 本地 HF 目录 / GGUF 转换加载（需 torch）
#   torch          -> transformers 生成与训练流水线
# 缺失时本地推理/训练会明确报「未安装后端」，绝不返回占位输出。
# 训练流水线在无 torch 时自动走纯 Python 真实梯度下降路径。
# ---------------------------------------------------------------------------

# 按需安装（体积较大，不建议在移动端安装）：
# llama-cpp-python>=0.2.90
# ctransformers>=0.2.27
# transformers>=4.45
# torch>=2.0
# cryptography   -> 云端快照加密同步（backend/app/runtime/cloud_sync.py 的 AES-256-GCM）。
#                   未安装时该模块仍可导入，只有真正加解密时才明确报错；
#                   对应测试 tests/test_cloud_sync.py 未安装时跳过。
